## Описание
Графическое приложение для планирования тренировок. Позволяет пользователю составлять расписание занятий, указывая дату, тип нагрузки и длительность. Реализована защита от дублирования ID при удалении записей.

## Функциональные возможности
1. **Добавление тренировки:** Поля: Дата, Тип, Длительность.
2. **Валидация ввода:** Проверка формата даты (ГГГГ-ММ-ДД) и положительности длительности.
3. **Просмотр и удаление:** Таблица всех операций с возможностью удаления.
4. **Фильтрация:** Поиск по типу и дате.
5. **Сохранение:** Данные хранятся в `workouts.json`.
6. **Уникальные ID:** Используется алгоритм генерации ID, устойчивый к удалению записей.
