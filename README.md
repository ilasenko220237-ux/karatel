## Описание
Графическое приложение для планирования тренировок. Позволяет пользователю составлять расписание занятий, указывая дату, тип нагрузки и длительность.

## Функциональные возможности
1. **Добавление тренировки:**
   - Поля: Дата, Тип тренировки, Длительность (мин).
   - Автоматическая проверка введенных данных.
2. **Валидация ввода:**
   - Дата должна быть в формате `ГГГГ-ММ-ДД`.
   - Длительность должна быть положительным числом.
3. **Просмотр списка:** Все добавленные тренировки отображаются в таблице.
4. **Фильтрация:**
   - Поиск по типу тренировки (например, "Бег").
   - Поиск по конкретной дате.
5. **Удаление:** Возможность удалить запись из плана.
6. **Сохранение данных:** Все данные сохраняются в файл `workouts.json` и не теряются после закрытия программы.
